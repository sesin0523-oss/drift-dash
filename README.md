# Drift Dash

탑뷰 2D 레이싱 게임입니다. 친구에게 링크를 보내면 친구는 **브라우저에서 바로** 같은 방에 들어와 함께 달립니다. 설치는 필요 없고, 한 방에 최대 6명까지 들어올 수 있습니다.

- 서버: C# ASP.NET Core (.NET 9). 웹페이지 제공, WebSocket 실시간 통신, 방 관리
- 게임: HTML5 Canvas + JavaScript. 외부 라이브러리와 엔진 없이 직접 구현
- 소리: Web Audio로 합성 (음원 파일 없음)

## 실행

```bash
dotnet run
```

브라우저에서 http://localhost:5080 을 엽니다. 로비에 나오는 **초대 링크**를 친구에게 보내면 같은 방으로 들어옵니다.

## 친구가 들어오는 방법

| 상황 | 방법 |
|---|---|
| 같은 와이파이 | 로비에 보이는 `http://192.168.x.x:5080/?room=코드` 링크를 그대로 보내기. 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용** |
| 다른 곳 (빠르게) | Cloudflare 임시 터널: `cloudflared tunnel --url http://localhost:5080` → `https://xxxx.trycloudflare.com` 주소가 나옴. 그 주소 뒤에 `/?room=코드`를 붙여 보내기. 내 PC가 켜져 있고 서버가 실행 중일 때만 접속 가능 |
| 다른 곳 (항상 켜두기) | Render.com 배포 (아래) |

### Render.com에 배포하기 (고정 주소)

코드는 공개 저장소 https://github.com/sesin0523-oss/drift-dash 에 있습니다.

1. https://render.com/deploy?repo=https://github.com/sesin0523-oss/drift-dash 를 엽니다.
2. Render에 로그인합니다(GitHub·Google 계정 가능, 신용카드 불필요).
3. 저장소의 `render.yaml` 설정이 자동으로 채워지면 **Apply / Deploy**를 누릅니다. 포함된 `Dockerfile`로 빌드하며 몇 분 걸립니다.
4. 끝나면 `https://drift-dash-xxxx.onrender.com` 같은 **고정 주소**가 생깁니다. 뒤에 `/?room=코드`를 붙여 친구에게 보내면 됩니다.

이후 GitHub에 코드를 올리면(push) Render가 자동으로 다시 배포합니다. 무료 요금제는 15분 동안 접속이 없으면 잠들어서, 첫 접속은 30~60초 걸릴 수 있습니다.

## 차 고르기

로비의 **내 차**에서 고릅니다(브라우저에 기억됨). 충돌 크기는 모두 같고 능력치만 다릅니다.

| 차 | 특징 |
|---|---|
| 밸런스 | 무난한 기본 차 |
| 스피드 | 최고 속도 690(기본 640)이지만 코너가 둔하고 가벼움 |
| 드리프트 | 잘 미끄러지고 미니 터보가 1.45배 빨리 참, 핸들이 잘 돎 |
| 탱크 | 무게 1.6배라 덜 밀리고 상대를 더 밀어냄. 웬만큼 세게 박아야 스핀(속도차 230 이상), 스핀 시간도 0.7배 |

차마다 **생김새가 완전히 다릅니다**: 밸런스는 세단, 스피드는 뾰족한 코와 큰 뒷날개의 스포츠카, 드리프트는 바퀴 위가 불룩한 와이드 펜더 차, 탱크는 짐칸과 범퍼 가드가 달린 트럭. 차 고르기 카드에 미리보기 그림이 나옵니다.

### 내 차 만들기 (차고)

차 고르기의 **+ 차 만들기**로 나만의 차를 만들 수 있습니다(최대 3대, 브라우저에 저장, 카드의 "고치기"로 수정·삭제).

- **생김새**: 모양 4가지(세단·스포츠카·드리프트카·트럭), 차 색, 포인트 색, 무늬 6가지(없음·가운데 줄·두 줄·체크·불꽃·사선), 지붕 번호(0~99), 이름(10자). 미리보기 차가 돌아가며 보여 줍니다.
- **능력치**: 속도·코너·드리프트·무게를 각 1~5로, **합계 12점** 안에서 나눕니다(3·3·3·3이 기본 차와 비슷). 속도를 올리면 가속이 조금 느려지고, 무게를 올리면 덜 밀리고 스핀도 잘 안 당합니다.
- 고른 커스텀 차는 서버가 다시 검사한 뒤(능력치 범위·합계, 색 형식) 다른 사람에게 전달되어 **모두의 화면에 같은 모양**으로 보입니다. 이상한 값이면 기본 차로 바뀝니다.

## AI 봇

방장은 로비에서 **봇 추가: 쉬움 / 보통 / 어려움**으로 컴퓨터 상대를 넣을 수 있습니다(사람 + 봇 최대 6대). 혼자서도 레이스가 되고, 발표 시연에도 좋습니다.

- **운전**: 속도에 비례한 거리만큼 앞의 도로 지점을 보고 핸들을 꺾고(pure pursuit), 더 먼 앞의 커브가 얼마나 꺾이는지 보고 미리 감속합니다. 바로 앞에 차가 있으면 차선을 옮겨 추월하고, 3초 동안 앞으로 거의 못 가면 후진해서 빠져나옵니다.
- **난이도**: 최고 속도 비율, 코너 진입 속도, 핸들 흔들림(실수)이 다르고, 어려움은 드리프트로 미니 터보를 씁니다. 아이템전에서는 봇도 상황을 보고 아이템을 씁니다(뒤에 차가 붙으면 바나나, 앞에 상대가 있으면 미사일, 미사일이 오면 보호막, 직선에서 부스터).
- **네트워크**: 봇은 **방장 브라우저가 운전**하고, 위치·완주·아이템을 `as: 봇id`를 붙여 보냅니다. 서버는 방장이 보낸 것만 봇의 것으로 인정합니다. 누가 봇을 박거나 맞히면 그 정보는 방장에게 가고, 방장 브라우저가 봇을 스핀시킵니다. 방장이 나가면 봇도 함께 나갑니다.

| 선셋 서킷 한 바퀴 (봇 4대 동시 주행, 3회 중간값) | 쉬움 26.9초 | 보통 23.0초 | 어려움 18.8초 |
|---|---|---|---|

## 팀전 (2:2, 3:3)

로비의 **대결: 팀전**을 고르면 레드와 블루로 나뉩니다. 내 이름 옆 팀 배지를 눌러 팀을 바꾸고(방장은 봇의 팀도 바꿀 수 있음), 정하지 않은 사람·봇은 인원이 적은 팀에 자동으로 들어갑니다. 스피드전·아이템전 둘 다 됩니다.

- **점수**: 순위 점수의 합. 1위 10, 2위 8, 3위 6, 4위 5, 5위 4, 6위 3, 완주 못함 0.
- 레이스 중 화면 위에 **현재 순위 기준 팀 점수**가 실시간으로 나오고, 차 밑에 팀 색 원판이 깔립니다.
- **같은 팀끼리는** 뒤 모서리를 박아도 스핀하지 않고, 같은 팀 바나나는 밟히지 않으며, 미사일은 같은 팀을 건너뛰고 앞의 상대 팀 차를 노립니다.
- **팀 부스터 게이지**: 팀원들이 드리프트(초당 6), 슬립스트림(초당 4), 상대 스핀시키기(+15)로 팀 공용 게이지를 채웁니다. 100이 되면 **팀 전원이 2.2초 부스트**를 받습니다. 게이지는 서버가 합산하므로 모든 화면이 같습니다(한 번에 20까지만 인정).
- **팀 슬립스트림**: 같은 팀 차 바로 뒤(40~170px, 같은 차선·같은 방향)에 붙으면 최고 속도 +8%, 가속 +25%. 차 옆으로 바람 줄기가 지나가고 "슬립스트림!"이 뜹니다. (직선 3초: 230 → 249km/h)
- **팀 채팅**: 채팅창 왼쪽 **전체/팀** 버튼(또는 입력 중 Tab)으로 팀원에게만 보낼 수 있습니다. 팀 채팅은 팀 색 "팀" 꼬리표가 붙습니다.
- **팀원 위치**: 화면 밖에 있는 팀원은 화면 가장자리에 팀 색 화살표와 이름·거리로 표시되고, 미니맵 점과 이름표도 팀 색입니다.

## 3판 2선승제

로비의 **경기 방식: 3판 2선승**을 고르면 여러 판의 결과를 이어서 셉니다. 개인전·팀전, 스피드전·아이템전 모두 됩니다.

- **개인전**: 판마다 1등이 1승. 먼저 2승하면 우승. 3판을 해도 2승한 사람이 없으면(셋이 1승씩 등) 세 판 동안 모은 순위 점수(1위 10, 2위 8, 3위 6…)가 가장 높은 사람이 우승.
- **팀전**: 판마다 팀 점수가 높은 팀이 1승(같으면 무승부). 먼저 2승한 팀이 우승, 3판 뒤 승수가 같으면 누적 팀 점수로.
- 판 사이 결과 화면에 **시리즈 전적표**(★ 승수, 누적 점수)가 나오고, 방장이 "N판째 준비하기"로 로비에 돌아가 다음 판 트랙을 고릅니다. 로비에도 진행 상황이 한 줄로 보이고, 레이스 중 화면 왼쪽 위에 "3판 2선승 · N판째"가 뜹니다.
- 진행 중에 대결 방식(개인전/팀전, 단판/3판)을 바꾸면 시리즈는 처음부터 다시 시작합니다. 시리즈가 끝난 뒤 시작하면 새 시리즈가 열립니다.

## 그랑프리 모드

로비의 **모드**에서 스피드전·아이템전과 나란히 **그랑프리**를 고를 수 있습니다. 그랑프리 전용 **긴 코스 4곳**을 차례로 달려 **포인트 합계**로 종합 우승을 가립니다 (1위 10, 2위 8, 3위 6, 4위 5, 5위 4, 6위 3점). 규칙은 스피드전과 같고(아이템 없음), 팀전이면 팀 포인트 합으로 겨룹니다.

| 라운드 | 코스 | 특징 (한 바퀴, 어려움 봇 기준) |
|---|---|---|
| 1 | 호수 순환로 | 큰 호수를 도는 고속 코스, 장애물 없음 (약 64초) |
| 2 | 대평원 하이웨이 | 끝없는 직선과 시케인, 직선 구간의 옆바람 (약 64초) |
| 3 | 알파인 고개 | 산을 넘는 긴 와인딩, 낭떠러지(떨어지면 견인)와 낙석 (약 64초) |
| 4 | 야간 도심 순환 (결승) | 불 켜진 대도시의 직각 코너, 네온 감전 벽 (약 42초) |

- 그랑프리 코스는 그랑프리 모드에서만 나오고, 진행 중에는 코스·경기 방식을 바꿀 수 없습니다.
- 라운드가 끝날 때마다 종합 포인트표, 4라운드가 끝나면 시상식.

### 랩타임과 섹터 기록

- 모든 레이스에서 화면 위쪽에 **섹터 기록(S1·S2·S3)** 과 **이번 랩 시간**이 나옵니다. 한 바퀴를 3구간으로 나눠 구간마다 시간을 재고, 내 최고 구간 기록보다 빠르면 **보라색**, 느리면 **노란색**과 함께 차이(±초)를 보여 줍니다.
- 왼쪽에는 최고 랩과 직전 랩. 스피드전·그랑프리의 한 바퀴 기록은 코스별 랭킹·고스트에 올라갑니다.

## 시상식

**단판이 끝나거나 3판 2선승이 끝나면** 결과 화면 전에 시상식이 나옵니다.

- 무대 조명 아래 **1·2·3등 단상**이 솟아오르고, 3등 → 2등 → 1등 순으로 차가 위에서 떨어져 통통 튀며 착지합니다. 1등에게는 왕관과 꽃가루, 팡파레.
- 단상에는 순위와 기록(단판: 완주 시간 / 시리즈: 승수·점수), 4등부터는 아래에 한 줄로 표시됩니다.
- **팀전**이면 "레드 팀 승리!"(팀 색)와 함께 **이긴 팀 선수들**이 단상에 오르고, 진 팀은 아래에 이름이 나옵니다. 비기면 "무승부!".
- 화면을 누르거나 Enter/Space(시작 1초 뒤부터), 또는 7.5초가 지나면 결과 화면으로 넘어가고, 결과 화면의 **시상식 다시 보기**로 다시 볼 수 있습니다.

## 관전과 휴대폰

- **관전만 하기**를 켜면 레이스에 나가지 않고 구경만 합니다(발표 때 화면을 띄워 두기 좋음). 자리가 꽉 찬 방에 들어와도 관전으로 들어갑니다.
- 관전 중이거나 **내가 먼저 완주한 뒤**에는 화면 아래 관전 바의 **◀ ▶**(또는 `[` `]`, `←` `→`)로 따라갈 차를 바꿉니다.
- **휴대폰**: 화면을 만지면 터치 조작으로 바뀝니다. 왼쪽 **조향 패드**는 손가락을 댄 곳에서 좌우로 끈 만큼 핸들이 꺾이는 아날로그 방식이고, 오른쪽에 아이템·브레이크·드리프트 버튼이 있습니다(가속은 자동). 세로 화면이면 "가로로 돌리면 더 넓게 보여요"를 잠깐 띄우고, 가로·세로·좁은 화면에 맞춰 버튼 크기가 바뀝니다.

## 기록·랭킹·고스트

- **스피드전**에서 한 바퀴를 돌 때마다 랩 타임이 서버 랭킹에 제출됩니다. 트랙별로 이름마다 최고 기록 하나씩, 상위 10명까지 남습니다. 아이템전은 운이 섞이므로 제외합니다.
- 로비에서 고른 트랙의 **TOP 5**가 보이고, 1위를 갱신하면 방 채팅에 "신기록!" 알림이 뜹니다.
- **고스트**: 트랙 1위가 달린 한 바퀴를 0.1초 간격 위치로 저장해 두었다가, 레이스 중 내 바퀴 시간에 맞춰 반투명한 차로 재생합니다. 누가 더 빠른지 바로 비교할 수 있고, **G**로 켜고 끕니다.
- **부정 기록 거르기**: 서버는 트랙 길이로 계산한 최소 시간(최고 부스트 속도로 안쪽 라인을 달려도 걸리는 시간)보다 빠른 기록과, 랩 시간과 고스트 프레임 수가 맞지 않는 기록을 거부합니다.
- 저장 위치: `data/records.json` (환경변수 `DATA_DIR`로 바꿀 수 있음). **Render 무료 요금제는 서버가 잠들거나 다시 배포되면 디스크가 초기화되어 랭킹도 사라집니다.** 영구 보관이 필요하면 유료 디스크나 외부 DB를 붙여야 합니다.

| API | 내용 |
|---|---|
| `GET /api/records` | 트랙별 TOP 10 `[[{name, time, date}], ...]` |
| `GET /api/ghost/{트랙번호}` | 1위 고스트 `{name, time, hz, frames:[x,y,a,...]}` (없으면 404) |

## 아이템전

로비에서 방장이 **모드: 아이템전**을 고르면, 트랙 세 곳에 무지개색 **? 상자**가 4개씩 놓입니다. 상자를 먹으면 0.9초 동안 뽑기를 한 뒤 아이템이 나오고, **Shift 또는 E**(휴대폰은 "아이템" 버튼)로 씁니다. 아이템은 한 번에 하나만 가질 수 있고, 먹은 상자는 3초 뒤 다시 나타납니다.

| 아이템 | 효과 |
|---|---|
| 바나나 | 차 뒤에 떨어뜨림. 밟은 차는 스핀 (내 바나나도 0.8초 뒤부터는 나도 밟힘). 40초 뒤 사라짐 |
| 미사일 | 바로 앞 순위 차를 쫓아가 명중하면 스핀. 맞을 사람 화면에는 "미사일 접근!" 경고. 1등이 쓰면 그냥 앞으로 날아감 |
| 보호막 | 5초 동안 스핀을 한 번 막아 줌 (박힘·바나나·미사일 모두) |
| 부스터 | 1.6초 부스트 |
| 부스터 ×3 | 부스트를 세 번 나눠 씀 (남은 횟수가 아이템 칸에 표시) |
| 기름 웅덩이 | 차 뒤에 떨어뜨림. 밟은 차는 1.1초 동안 미끄러지고 속도가 줄어듦 |
| 전기 충격 | 다른 모든 차(같은 팀 제외)가 1.5초 동안 감전되어 느려짐. 보호막이 막아 줌 |
| 먹물 | 나보다 앞선 차들의 화면 가운데가 3.5초 동안 먹물로 가려짐 |
| 자석 | 2.5초 동안 바로 앞 순위 차 쪽으로 끌려가며 조금 빨라짐 |
| 투명 망토 | 3초 동안 반투명해져 차·바나나·기름·미사일을 통과 |

**순위 보정**: 1등은 바나나·보호막(방어용)이 주로 나오고, 꼴찌는 미사일 36%·부스터 33%로 공격과 가속 아이템이 잘 나옵니다.

**네트워크**: 자기 차는 자기가 판정한다는 원칙 그대로입니다. 바나나와 미사일은 쓴 사람이 `obj` 로 알려 모두의 화면에 같은 물체가 생기고, 밟았는지와 맞았는지는 **맞는 사람의 브라우저**가 판정해서 `objHit` 로 알립니다. 미사일은 모든 화면에서 같은 규칙(초당 980px, 초당 5.5라디안 회전)으로 목표를 쫓아가서 거의 같게 보입니다. 서버는 아이템전일 때만, 정해진 종류(바나나·미사일·기름)만 중계합니다. 전기 충격·먹물은 `fx` 로 모두에게 알리고, 각 브라우저가 자기 차(방장은 봇도)에 적용할지 판정합니다.

## 몸싸움: 스핀과 길 막기

차끼리의 충돌은 차 모양 그대로의 **회전된 직사각형**으로 계산합니다(분리축 검사, SAT). 그래서 범퍼끼리 평평하게 맞닿습니다.

| 상황 | 결과 |
|---|---|
| 앞차 **뒤 범퍼 가운데**(±6px)를 박음 | 밀기만 함. 뒤차 속도가 앞차 속도로 줄어듦 |
| 앞차가 내 주행 라인에 들어와 있음 | **길 막기**. 차 폭(20px)의 절반 이상 겹치면 뒤차가 빠져나가지 못함 |
| 내 차 **앞부분**으로 상대 **뒤쪽 모서리**(8~14px 옆)를 속도차 140 이상으로 박음 | 상대가 **스핀**. 약 1~1.4초 동안 빙글빙글 돌며 조작 불능, 속도 약 1/3로 감소 |
| 옆구리 비비기, 천천히 닿기, 정면충돌 | 스핀 없음 |

- 스핀이 끝난 뒤 1.2초 동안은 다시 스핀하지 않습니다(연속 스핀 방지). 같은 상대는 1.2초에 한 번만 스핀시킬 수 있습니다.
- 맞은 쪽 모서리에 따라 도는 방향이 달라집니다(오른쪽 뒤를 맞으면 꼬리가 반대로 밀림).
- 스핀 중인 차 위에는 별이 돌고, 화면 위에 "A → B 스핀!" 알림이 뜹니다.

**네트워크 처리**: 박은 사람의 화면 기준으로 판정해서 서버를 거쳐 맞은 사람에게 전달하고, 맞은 사람의 브라우저가 실제로 차를 돌립니다. 상대 차는 원래 100ms 과거 위치로 그려지는데, 이번에 속도와 회전 속도로 **"지금 이 순간" 위치를 추정**해서 그리고 충돌도 그 위치로 계산하도록 바꿨습니다. 그래서 앞에서 막거나 뒤를 박을 때 두 화면이 거의 같습니다.

## 채팅

- 로비와 결과 화면에서는 패널 아래에 채팅창이 있고, 레이스 중에는 왼쪽 아래에 메시지가 떴다가 8초 뒤 사라집니다.
- 입장, 퇴장, 완주 순위가 회색 안내 문구로 나옵니다. 늦게 들어온 사람도 최근 대화 30개를 볼 수 있습니다.
- 한 번에 120자까지, 4초에 5개까지 보낼 수 있습니다(도배 방지).
- 받은 메시지는 글자로만 표시하므로, 누가 HTML이나 스크립트를 보내도 실행되지 않습니다.
- 휴대폰에서는 레이스 중 "채팅" 버튼으로 열고, 안 읽은 메시지 수가 표시됩니다.

휴대폰으로 열면 화면을 처음 만질 때 터치 버튼이 나옵니다(가속은 자동).

## 게임 규칙

- 방장(처음 들어온 사람)이 트랙(12종: 선셋 서킷, 협곡 헤어핀, 네온 시티, 도넛 링, 스노우 밸리, 해안 고속도로, 화산 분지, 숲속 와인딩, 공항 활주로, 사막 오아시스, 항구 부두, 절벽 고개 + 그랑프리 전용 긴 코스 4곳)과 바퀴 수(1~5)를 정하고 시작합니다.
- **드리프트 물리**: 차 머리가 돌 때 속도는 일부만 따라 돕니다(평소 93%, Space 55%). 따라가지 못한 만큼이 옆미끄럼이 되고, 접지력이 그것을 줄여 줍니다. 눈길(스노우 밸리)은 접지력이 70%라 평소에도 더 미끄러집니다. 혼자서도 연습할 수 있습니다.
- 체크포인트를 순서대로 지나야 바퀴가 올라갑니다(지름길·역주행 방지).
- 노란 화살표 발판을 밟으면 부스트가 나가고, 잔디에서는 느려지며, 바깥 타이어 벽에 부딪히면 튕겨 나갑니다.
- 1등이 들어온 뒤 30초 안에 완주하지 못하면 "완주 못함"으로 처리됩니다.
- 레이스 중에 들어온 사람은 관전하다가 다음 레이스부터 참가합니다.

**네트워크 방식**: 각자 **자기 차는 자기 브라우저에서 계산**합니다. 그래서 내 차는 핑과 상관없이 즉시 반응합니다. 위치는 초당 20번 서버로 보내고, 서버는 같은 방 사람들에게 그대로 중계합니다. 상대 차는 받은 위치를 100ms 늦게, 앞뒤 두 위치 사이를 섞어서 그리기 때문에 부드럽게 보입니다. 출발 시각은 서버가 정하고, 각 브라우저는 핑으로 서버 시계와의 차이를 재서 모두 같은 순간에 출발합니다.

**한계**: 완주 기록과 스핀 판정은 각 브라우저가 계산해서 보내므로, 마음먹고 조작하면 속일 수 있습니다(친구끼리 하는 게임이라 허용). 차끼리 부딪히면 각자 화면에서 밀려나는 방식이라, 핑이 크거나(150ms 이상) 급커브에서는 위치 추정이 빗나가 충돌이 어색할 수 있습니다.
