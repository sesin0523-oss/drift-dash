# Drift Dash

탑뷰 2D 레이싱 게임입니다. 친구에게 링크를 보내면 친구는 **브라우저에서 바로** 같은 방에 들어와 함께 달립니다. 설치는 필요 없고, 한 방에 최대 6명까지 들어올 수 있습니다.

- 서버: C# ASP.NET Core (.NET 9). 웹페이지 제공, WebSocket 실시간 통신, 방 관리
- 게임: HTML5 Canvas + JavaScript. 외부 라이브러리와 엔진 없이 직접 구현
- 소리: Web Audio로 합성 (음원 파일 없음)

## 실행

```bash
dotnet run
```

브라우저에서 http://localhost:5080 을 엽니다. 로비에 나오는 **초대 링크**를 친구에게 보내면 같은 방으로 들어옵니다.

## 친구가 들어오는 방법

| 상황 | 방법 |
|---|---|
| 같은 와이파이 | 로비에 보이는 `http://192.168.x.x:5080/?room=코드` 링크를 그대로 보내기. 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용** |
| 다른 곳 (빠르게) | Cloudflare 임시 터널: `cloudflared tunnel --url http://localhost:5080` → `https://xxxx.trycloudflare.com` 주소가 나옴. 그 주소 뒤에 `/?room=코드`를 붙여 보내기. 내 PC가 켜져 있고 서버가 실행 중일 때만 접속 가능 |
| 다른 곳 (항상 켜두기) | 이 폴더를 GitHub에 올리고 Render.com에서 "New Web Service → Docker"로 배포. 포함된 `Dockerfile`을 그대로 씁니다. 무료 요금제는 한동안 접속이 없으면 잠들어서 첫 접속이 30초쯤 느립니다 |

## 조작

| 키 | 동작 |
|---|---|
| ↑ / W | 가속 |
| ↓ / S | 브레이크, 후진 |
| ← → / A D | 조향 |
| Space | 드리프트. 길게 미끄러지다 놓으면 **미니 터보** (게이지 파랑 → 주황) |

## 아이템전

로비에서 방장이 **모드: 아이템전**을 고르면, 트랙 세 곳에 무지개색 **? 상자**가 4개씩 놓입니다. 상자를 먹으면 0.9초 동안 뽑기를 한 뒤 아이템이 나오고, **Shift 또는 E**(휴대폰은 "아이템" 버튼)로 씁니다. 아이템은 한 번에 하나만 가질 수 있고, 먹은 상자는 3초 뒤 다시 나타납니다.

| 아이템 | 효과 |
|---|---|
| 바나나 | 차 뒤에 떨어뜨림. 밟은 차는 스핀 (내 바나나도 0.8초 뒤부터는 나도 밟힘). 40초 뒤 사라짐 |
| 미사일 | 바로 앞 순위 차를 쫓아가 명중하면 스핀. 맞을 사람 화면에는 "미사일 접근!" 경고. 1등이 쓰면 그냥 앞으로 날아감 |
| 보호막 | 5초 동안 스핀을 한 번 막아 줌 (박힘·바나나·미사일 모두) |
| 부스터 | 1.6초 부스트 |

**순위 보정**: 1등은 바나나·보호막(방어용)이 주로 나오고, 꼴찌는 미사일 36%·부스터 33%로 공격과 가속 아이템이 잘 나옵니다.

**네트워크**: 자기 차는 자기가 판정한다는 원칙 그대로입니다. 바나나와 미사일은 쓴 사람이 `obj` 로 알려 모두의 화면에 같은 물체가 생기고, 밟았는지와 맞았는지는 **맞는 사람의 브라우저**가 판정해서 `objHit` 로 알립니다. 미사일은 모든 화면에서 같은 규칙(초당 980px, 초당 5.5라디안 회전)으로 목표를 쫓아가서 거의 같게 보입니다. 서버는 아이템전일 때만, 정해진 종류(바나나·미사일)만 중계합니다.

## 몸싸움: 스핀과 길 막기

차끼리의 충돌은 차 모양 그대로의 **회전된 직사각형**으로 계산합니다(분리축 검사, SAT). 그래서 범퍼끼리 평평하게 맞닿습니다.

| 상황 | 결과 |
|---|---|
| 앞차 **뒤 범퍼 가운데**(±6px)를 박음 | 밀기만 함. 뒤차 속도가 앞차 속도로 줄어듦 |
| 앞차가 내 주행 라인에 들어와 있음 | **길 막기**. 차 폭(20px)의 절반 이상 겹치면 뒤차가 빠져나가지 못함 |
| 내 차 **앞부분**으로 상대 **뒤쪽 모서리**(8~14px 옆)를 속도차 140 이상으로 박음 | 상대가 **스핀**. 약 1~1.4초 동안 빙글빙글 돌며 조작 불능, 속도 약 1/3로 감소 |
| 옆구리 비비기, 천천히 닿기, 정면충돌 | 스핀 없음 |

- 스핀이 끝난 뒤 1.2초 동안은 다시 스핀하지 않습니다(연속 스핀 방지). 같은 상대는 1.2초에 한 번만 스핀시킬 수 있습니다.
- 맞은 쪽 모서리에 따라 도는 방향이 달라집니다(오른쪽 뒤를 맞으면 꼬리가 반대로 밀림).
- 스핀 중인 차 위에는 별이 돌고, 화면 위에 "A → B 스핀!" 알림이 뜹니다.

**네트워크 처리**: 박은 사람의 화면 기준으로 판정해서 서버를 거쳐 맞은 사람에게 전달하고, 맞은 사람의 브라우저가 실제로 차를 돌립니다. 상대 차는 원래 100ms 과거 위치로 그려지는데, 이번에 속도와 회전 속도로 **"지금 이 순간" 위치를 추정**해서 그리고 충돌도 그 위치로 계산하도록 바꿨습니다. 그래서 앞에서 막거나 뒤를 박을 때 두 화면이 거의 같습니다.

## 채팅

- 로비와 결과 화면에서는 패널 아래에 채팅창이 있고, 레이스 중에는 왼쪽 아래에 메시지가 떴다가 8초 뒤 사라집니다.
- 입장, 퇴장, 완주 순위가 회색 안내 문구로 나옵니다. 늦게 들어온 사람도 최근 대화 30개를 볼 수 있습니다.
- 한 번에 120자까지, 4초에 5개까지 보낼 수 있습니다(도배 방지).
- 받은 메시지는 글자로만 표시하므로, 누가 HTML이나 스크립트를 보내도 실행되지 않습니다.
- 휴대폰에서는 레이스 중 "채팅" 버튼으로 열고, 안 읽은 메시지 수가 표시됩니다.

휴대폰으로 열면 화면을 처음 만질 때 터치 버튼이 나옵니다(가속은 자동).

## 게임 규칙

- 방장(처음 들어온 사람)이 트랙(4종: 선셋 서킷, 협곡 헤어핀, 네온 시티, 도넛 링)과 바퀴 수(1~5)를 정하고 시작합니다. 혼자서도 연습할 수 있습니다.
- 체크포인트를 순서대로 지나야 바퀴가 올라갑니다(지름길·역주행 방지).
- 노란 화살표 발판을 밟으면 부스트가 나가고, 잔디에서는 느려지며, 바깥 타이어 벽에 부딪히면 튕겨 나갑니다.
- 1등이 들어온 뒤 30초 안에 완주하지 못하면 "완주 못함"으로 처리됩니다.
- 레이스 중에 들어온 사람은 관전하다가 다음 레이스부터 참가합니다.

## 구조

```
Program.cs          웹서버 시작, /ws(WebSocket), /api/info(같은 와이파이 주소)
Rooms.cs            Client(보내기 큐), Lobby(방 목록), Room(참가자·출발 시각·중계·순위·채팅)
wwwroot/index.html  로비, 결과, 터치 버튼
wwwroot/js/
  main.js    게임 흐름 (로비 → 카운트다운 → 레이스 → 결과), 입력, HUD
  track.js   트랙 3종: 곡선 생성, 가장 가까운 도로 지점, 체크포인트, 부스터, 출발 격자
  car.js     차 물리 (앞/옆 속도 분리 → 접지력·드리프트, 미니 터보, 벽 충돌),
             차끼리 직사각형 충돌(SAT)·길 막기·뒤 모서리 스핀 판정, 바퀴 계산
  net.js     WebSocket, 서버 시계 맞추기, 상대 차 보간 + 현재 위치 추정(RemoteCar)
  render.js  트랙·차·스키드 자국·연기 그리기, 미니맵, 화면 배율 대응
  audio.js   엔진음, 타이어 소리, 카운트다운, 부스트
  chat.js    채팅창 (로비·결과에선 패널 안, 레이스 중엔 화면 왼쪽 아래)
  items.js   아이템전: 상자, 순위별 뽑기, 바나나·미사일·보호막·부스터, 아이콘 그리기
```

**네트워크 방식**: 각자 **자기 차는 자기 브라우저에서 계산**합니다. 그래서 내 차는 핑과 상관없이 즉시 반응합니다. 위치는 초당 20번 서버로 보내고, 서버는 같은 방 사람들에게 그대로 중계합니다. 상대 차는 받은 위치를 100ms 늦게, 앞뒤 두 위치 사이를 섞어서 그리기 때문에 부드럽게 보입니다. 출발 시각은 서버가 정하고, 각 브라우저는 핑으로 서버 시계와의 차이를 재서 모두 같은 순간에 출발합니다.

**한계**: 완주 기록과 스핀 판정은 각 브라우저가 계산해서 보내므로, 마음먹고 조작하면 속일 수 있습니다(친구끼리 하는 게임이라 허용). 차끼리 부딪히면 각자 화면에서 밀려나는 방식이라, 핑이 크거나(150ms 이상) 급커브에서는 위치 추정이 빗나가 충돌이 어색할 수 있습니다.

## 검증 (자동 운전 테스트)

| 트랙 | 한 바퀴 | 최고 속도 | 도로 사이 최소 간격 |
|---|---|---|---|
| 선셋 서킷 | 약 17.5초 | 230 km/h | 1064px |
| 협곡 헤어핀 | 약 19초 | 331 km/h (부스트) | 779px |
| 네온 시티 (신규) | 약 10.5초 | 230 km/h | 865px |
| 도넛 링 | 약 9초 | 230 km/h | 920px |

서버 흐름(방장 권한, 위치 중계, 완주 순위, 로비 복귀, 방장 위임)은 가짜 접속 두 개로 확인했습니다.
